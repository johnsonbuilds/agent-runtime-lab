# Core Concepts to Remember

## Agent Loop

> **The Agent Loop is an iterative execution cycle in which the LLM decides the next action, the runtime executes tools, and the resulting observations are fed back into the context for the next decision.**

## Observation

> **A tool result is an observation from the environment that gives the LLM new information about the current task.**

## Conversation History

> **Conversation history provides contextual information about what happened previously in the interaction.**

## Agent State

> **Agent state represents the current structured state of the task and should not depend entirely on raw conversation history.**

## Context Management

> **Context management keeps the information needed for the next reasoning step within the model's context and budget.**

## Context Compression

> **Context compression reduces redundant historical information while preserving critical task information.**

## Reliability

> **A production agent needs more than a basic loop: it needs termination control, timeout handling, retries, recovery, observability, and robust state management.**

# Useful Interview Phrases

### 1. Basic Loop

> **A minimal agent can be implemented as an iterative loop.**

### 2. Runtime vs LLM

> **The runtime is responsible for execution, while the LLM is responsible for interpreting observations and deciding the next action.**

### 3. Observation

> **The tool result provides an observation from the environment, which the LLM can use in the next reasoning step.**

### 4. Context

> **The observation needs to be interpreted in the context of the overall task, not in isolation.**

### 5. Critical State

> **We shouldn't rely on summarization alone for critical state.**

### 6. Context Compression

> **We can compress historical context while preserving important user constraints, key decisions, and the current task state.**

### 7. Infinite Loop

> **A maximum iteration limit is the simplest safeguard, but it isn't sufficient by itself.**

### 8. Tool Failure

> **Not every tool error is retryable. We need to classify errors and apply an appropriate recovery strategy.**

### 9. Production Reliability

> **The basic loop is relatively simple. The hard part is making it reliable in production.**

### 10. Agent Reliability

> **As agents move toward long-running autonomous tasks, state management, recovery, observability, and execution guarantees become increasingly important.**
